# Pancake Stacker

A portrait-oriented casual arcade stacking game prototype built with Godot 4 and GDScript.

## Project status

Pre-production. The current repository documentation defines the game vision and incremental development process. The initial Godot project foundation is the first implementation task.

## Start here

1. Read [`game_design.md`](game_design.md) for the game concept and rules.
2. Read [`docs/AI_INSTRUCTIONS.md`](docs/AI_INSTRUCTIONS.md) before asking an AI assistant to modify the project.
3. Read [`docs/TECHNICAL_DESIGN.md`](docs/TECHNICAL_DESIGN.md) for current technical guidance.
4. Read [`docs/TASKS.md`](docs/TASKS.md) for the development roadmap and authorization status.

## Development rule

Only the task explicitly approved by the project owner may be implemented. Initially, that is TASK-001 — Create the Godot project foundation.

One task → one implementation → one test → one review → approval before the next task.

- Godot 4
